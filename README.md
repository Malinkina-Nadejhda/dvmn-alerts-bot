# `dvmn_alerts_bot.py`

Telegram-бот для уведомлений от [Devman](https://dvmn.org/).

Телеграм-бот для отправки уведомлений с сайта [dvmn.org](https://dvmn.org/) о проверенных работах. 
Бот постоянно опрашивает API платформы и, как только работа проходит ревью, моментально присылает сообщение со статусом проверки и ссылкой на проверенный урок.

**Как установить:**

- Убедитесь, что у вас установлен `Python` версии 3.13 или выше.
- Kлонируйте репозиторий с проектом на свой компьютер.
- Используйте `pip` для установки зависимостей:

```bash
pip install -r requirements.txt
```


## Настройка окружения

1. Получите токен для бота у официального бота [@BotFather](https://t.me/botfather).
2. Узнайте свой chat id (например, с помощью бота [@userinfobot](https://t.me/userinfobot)).
3. Получите персональный API-токен [Девмана](https://dvmn.org/api/docs/)
3. Создайте файл `.env` в корне проекта по образцу файла `.env.example`.
4. Добавьте в `.env` ваши реальные данные:

   ```env
    DVMN_TOKEN=ваш_токен
    TG_TOKEN=ваш_токен
    BOT_CHAT_ID=ваш_id_чата
   ```
## Запуск
 Вы можете использовать флаг `--help` для вывода подробной справки по аргументам.

 ```bash
# Запуск бота (chat_id будет взят из .env файла)
python .\dvmn_alerts_bot.py

# Запуск бота c принудительным указанием chat_id через аргумент
python .\dvmn_alerts_bot.py --chat_id 12345678910
```
